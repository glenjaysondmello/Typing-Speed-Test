# Typing Speed Test Game

---

A fun and interactive typing game built with JavaScript, HTML, and CSS. This game helps users improve their typing speed and accuracy in an engaging way.  

## 🚀 Features  

- 🔹 **Random word generation** for typing practice  
- ⏳ **Countdown timer** to add a challenge  
- 📊 **Score tracking** to measure performance  
- 📱 **Responsive design** for all screen sizes  

## 🛠️ Installation  

### 1️⃣ Clone the Repository  

```sh  
git clone https://github.com/glenjaysondmello/Typing-Speed-Test.git  
```  

### 2️⃣ Navigate to the Project Folder  

```sh  
cd TypinG-Speed-Test
```  

### 3️⃣ Open the Game in Your Browser  

Since this is a static project, no server setup is required.  

#### For macOS:  

```sh  
open index.html  
```  

#### For Windows:  

```sh  
start index.html  
```  

#### For Linux:  

```sh  
xdg-open index.html  
```  

Alternatively, manually open `index.html` in your browser.  

## 🎮 How to Play  

1️⃣ Start typing the displayed word.  
2️⃣ Your **score updates** based on speed and accuracy.  
3️⃣ The game **ends when the timer reaches zero**.  
4️⃣ Try again to **beat your high score**!
